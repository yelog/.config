---
name: task-plan
description: Turn a task analysis into a complete implementation plan and change scope.
disable-model-invocation: true
---

Read the analysis artifact first. Produce a bite-sized implementation plan with
files, tests, verification commands, acceptance criteria, and required versus
optional checks. Write the plan and an explicit change-scope.json containing
repository-relative concrete files or directories. Do not modify business code.
Write only the current attempt's receipt JSON after the artifacts are complete.
